# 考研英语二高分写作教练 Skill (Kaoyan English II Writing Skill)

> **专为考研英语二冲刺 21-23+ 高分段定制**（大作文 13-14 分，小作文 8.5-9.5 分）  
> 深度融合**周思成老师**（地道情商、反模板倒装/非谓语、对象感与交际语境）与**石雷鹏老师**（模块化功能骨架、九达因果论据库、应试高分结构）。

---

## 🌟 项目亮点

1. **反模板低幼套话**：
   - 彻底摒弃 `Given is a...`、`With the development of...`、`Firstly / Secondly` 等低档机械句式。
   - 首段引入**方位倒装**（`Portrayed in the chart is...`）与**非谓语分词结构**，抓准极值与显著对比。
2. **双核因果论据库**：
   - 第二段拒绝流水账，采用“宏观社会大背景（经济繁荣/数字赋能）+ 微观个体诉求（竞争压力/身心调节/观念升级）”的双核递进论证。
3. **小作文全场景覆盖**：
   - 重点突破近五年高频考向**互动答复信（Reply to Email）**，具备地道交际礼貌与情商。
   - 告示通知类支持**周思成小标题法**（Time and Venue, Highlights, Registration），版面层次分明，阅卷老师秒给高分。
4. **强制双语对照与背诵骨架**：
   - 每次生成均附带精准中文译文、高分词汇提炼与 3 分钟极速背诵留白骨架。
