# 考研英语二高分写作教练 Skill (marzhou-kaoyan-writing)

> **专为考研英语二冲刺 21-23+ 高分段定制**（大作文 13-14 分，小作文 8.5-9.5 分）  
> 深度融合**周思成老师**（地道情商、反模板倒装/非谓语、对象感与交际语境）与**石雷鹏老师**（模块化功能骨架、九达因果论据库、应试高分结构）。  
> 内置 **2010—2026 年共 17 年 34 道全真试题大库与全套图表原图**，具备智能真题检索与溯源能力。

---

## 🌟 项目核心亮点

1. **📚 2010—2026 年全真题库内置 & 自动检索溯源**：
   - 完整收录 **2010 至 2026 年**英语二全部 17 道大作文（柱状图、饼状图、折线图、表格）与 17 道小作文（答复信、建议信、告示通知、邀请信、感谢信等）。
   - **智能检索识别**：当用户询问或输入任何考研作文题目/关键词时，AI **首先自动检索题库**，标明出自哪一年真题、图表类型、考查背景及命题暗线，再提供量身定制的高分范文。
2. **✨ 反套路、反低幼句式**：
   - 彻底摒弃 `Given is a...`、`With the development of...`、`Firstly / Secondly` 等中档模板句式。
   - 首段引入**方位介词倒装**（`Portrayed in the chart is...`）与**非谓语分词结构**，抓准极值、拐点与显著对比。
3. **🧠 双核因果论据库**：
   - 第二段拒绝空话流水账，采用“宏观社会大背景（经济繁荣/数字赋能）+ 微观个体诉求（竞争压力/身心调节/观念升级）”的双核递进论证体系。
4. **💌 小作文全场景覆盖**：
   - 重点突破近五年高频考向**互动答复信（Reply to Email）**，具备地道交际礼貌与情商。
   - 告示通知类支持**周思成小标题法**（Time and Venue, Highlights, Registration），版面层次分明，阅卷老师秒给高分。
5. **🇨🇳 强制双语对照与极速背诵骨架**：
   - 每次生成均强制附带**地道精准中文译文**、**高分词汇提炼**与 **3 分钟极速背诵留白骨架**。

## 🚀 在 Antigravity 中使用

将本仓库克隆或复制到 Antigravity 的技能目录即可即刻生效：
```bash
# 全局技能路径
~/.gemini/config/skills/kaoyan-writing/
```

当向 AI 发送写作指令（例如输入：*“写一下2024年的大作文”* 或 *“帮我写一篇关于选修课调查的图表作文”*）：
1. AI 会**自动先检索 2010-2026 真题库**，标出该题目为 2024 年真题及图表特征；
2. 按照周思成×石雷鹏融合专属高分框架生成中英双语范文、高分亮点及背诵骨架！
